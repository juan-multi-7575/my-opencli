# Extension home: canonical source in the repo, deployed by symlink

The opencli-bridge source lives in this repo at `extensions/opencli-bridge/` and is deployed into `~/.pi/agent/extensions/opencli-bridge` (the pi auto-discovery path) as a symlink, so pi hot-reloads the repo copy. The alternative — leaving it unversioned in `~/.pi` — was rejected because the extension is opencli-ecosystem tooling with real branching logic that needs diffs, history, and revert, and this repo already ships agent-facing opencli assets (`skills/`). Assumption to verify at implementation time: pi's glob discovery (`~/.pi/agent/extensions/*/index.ts`) follows directory symlinks; if `/reload` rejects the symlink, fall back to a `scripts/sync-bridge.sh` copy step. A side effect: the repo's auto-checkpoint commits every bridge edit.
