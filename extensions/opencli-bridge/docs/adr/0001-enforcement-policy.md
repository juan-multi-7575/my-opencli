# Enforcement: strict blocking with a real OPENCLI_BYPASS escape

The Bridge blocks bash commands that scrape public web URLs with curl/wget/requests/fetch. The block message promised an `OPENCLI_BYPASS=1` escape hatch that no code ever read — the promise was a lie. We keep the strict policy (all public-URL scraping is blocked, redirecting the agent to the Tools) and make the escape real: when `OPENCLI_BYPASS=1` is set in the environment, the command runs. Local and private-network traffic (`localhost`, `192.168.*`, `10.*`, `172.*`) is never blocked. The rejected alternative — blocking only OpenCLI-supported sites and letting unknown public URLs through — was declined because the system prompt already tells the agent never to curl public URLs; a hole there would quietly reintroduce scraping.
