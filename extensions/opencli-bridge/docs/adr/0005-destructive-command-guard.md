# Destructive opencli commands require explicit confirmation

`opencli_run` can execute write commands that mutate or destroy state (delete, unfollow, unsubscribe, unlike, block, logout, … — 339 write commands exist in the registry). The Bridge gates the destructive subset: a destructive command is NOT run unless the caller passes `confirm: true`, which the agent is instructed to set only when the user explicitly asked for it. Non-destructive write commands still run but their output is annotated with `⚠ write command — mutates state`. The destructive set is a regex over verified registry verbs (`delete|remove|unfollow|unsubscribe|uncheck|unlike|cancel|clear|revoke|logout|ban|mute|block`), with `remove-bg` exempted (a generator, not destructive). Rejected: blocking all write commands (kills legitimate posting workflows) and blocking none (lets an agent delete a user's tweet off an ambiguous instruction).
